General

Settings, tabs and shortcut remaps sync to your other computers through your browser's own sync (when it is on). No Keyline account needed. Account names stay on each computer.

Open the command palette

Click the key, then press a new shortcut with Cmd, Ctrl or Option. With text selected in an email you're writing, Cmd+K always inserts a link (Gmail's own shortcut), so you only need to change this to get Cmd+K back everywhere else in the editor too.

Theme

Restyles the command palette, cheat sheet, toasts, tab bar and settings on Gmail and Calendar. Each theme follows your system's light or dark mode and syncs with your other settings.

Split inbox tabs

A tab bar at the top of Gmail. Each tab is any Gmail search (is:unread, label:Clients, from:boss@x.com…). Add, rename, and remove tabs from the gear icon in the tab bar inside Gmail.

Accounts

Learned automatically as you visit each account. Switch with g 0, g 1, g 2 (the number is the /mail/u/N index). Edit the display names if you like.

Keyboard shortcuts

Click any key cell to record a new binding. Press a single key, or start with g to build a chord (e.g. g then i). Esc cancels, Enter commits. Single-key actions drive Gmail's own toolbar, so turn on Settings → See all settings → Keyboard shortcuts on in Gmail.

Open Gmail once so the command list can load.
